# 🌐 Darshana R - Personal Portfolio

A modern and responsive personal portfolio website built using React and Vite, designed to showcase projects, technical skills, education, and professional interests in an interactive and visually appealing way.

The portfolio features a sleek dark-themed UI with glassmorphism effects, smooth animations, and responsive layouts optimized for all screen sizes.

---

## 🚀 Features

- Modern dark-mode UI with gradient aesthetics
- Responsive design for mobile, tablet, and desktop
- Glassmorphism-inspired cards and navigation
- Interactive technical skills section
- Featured projects showcase
- Smooth scrolling and micro animations
- Organized and reusable React component structure

---

## 🛠️ Tech Stack

### Frontend
- React JS
